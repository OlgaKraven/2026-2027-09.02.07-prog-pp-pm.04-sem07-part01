Вариант 01

Библиотечные выдачи

  1. 01

    Предметная область

    Организация ведёт CSV-журнал: объект — книга, ответственный — читатель, контрольное действие — возврат. Срок в Due нужен для контроля незавершённых заявок. Item означает «книга», Owner — «читатель», Due — срок действия «возврат».

  2. 02

    Вход и индивидуальные данные

    Использовать принятую WPF-основу области «Библиотечные выдачи»; при отсутствии результата — предоставленную основу. Загрузить variant-01.csv: корректны первые две записи, неполная запись находится в физической строке 4. Значения Owner: Читатель А; Читатель Б; Читатель В. Для отдельной проверки отбора использовать variant-check-01.csv с шестью корректными строками.

  3. 03

    Самостоятельное правило

    Задача «Просроченные возвраты». Оставить только открытые записи с Due раньше контрольной даты; упорядочить по Due, затем Id. На контрольном CSV при дате 01.10.2026 ожидаемый порядок Id: 105, 101, 103.

    Проверка. Установить 01.10.2026 в поле «Контрольная дата». Сопоставить подходящие строки и порядок Id с условием до запуска.
