Назначение

ПП.04.01 «Сопровождение и обслуживание программного обеспечения компьютерных систем». Объём первой части — 216 часов. Работа продолжается в следующей части практики.

Исходная система

Вы получаете готовое приложение Windows Forms на C# и CSV-файл своего варианта. В исходной версии есть три воспроизводимых дефекта: авария импорта при неполной строке, несовместимый экспорт, неверный подсчёт просроченных заявок.

Итог

Передайте исправленный проект, исходный и экспортированный CSV, журнал дефектов, протокол проверок, инструкцию пользователю и один заполненный отчёт Markdown. Покажите запуск приложения и скриншоты результатов.

Файлы стенда

Скачайте ServiceDesk-source.zip, demo.csv и demo-valid.csv на сайте. Для индивидуальной работы используйте CSV своей карточки. Исправленное демонстрационное решение доступно в ServiceDesk-fixed-example.zip для разбора после самостоятельной диагностики.

Единая задача для всех вариантов

Общее производственное задание

Диагностика

Соберите исходный проект. Воспроизведите D1 на неполной записи своего CSV, D2 экспортом и повторным импортом, D3 на завершённой записи с прошедшей датой. Зафиксируйте вход, действие, ожидаемое и фактическое поведение.

Исправление

Сделайте импорт устойчивым: проверьте число полей, целый идентификатор, дату dd.MM.yyyy и допустимый статус; плохую строку пропускайте с номером и причиной, а корректные загружайте. Экспортируйте пять полей через точку с запятой и ту же дату. Просроченными считайте только незавершённые записи с датой раньше текущей.

Проверки

Проверьте неполную строку, неверную дату, пустой файл с заголовком, корректные записи, повторный импорт экспортированного CSV и граничную дату сегодня. Сравните число и содержимое записей до и после обмена.

Обновление

Подготовьте пакет обновления с версией, списком исправлений, резервной копией исходных данных, порядком замены и отката. Напишите короткую инструкцию пользователю: открыть файл, понять предупреждения, сохранить результат и восстановить копию.

Проверяемые результаты

Критерии приёмки

Работоспособность

Приложение собирается и запускается на Windows. Корректные строки доступны после импорта; ошибка одной строки не уничтожает остальные. Экспорт повторно читается без изменения значений.

Обоснованность

Каждое исправление связано с воспроизведённым дефектом. Протокол содержит вход, ожидаемый и фактический результат. Дополнительное условие варианта проверено отдельно.

Передача

Рядом с программой есть понятные сведения о версии, составе, резервном копировании и откате. Отчёт не содержит выдуманных измерений.
