Задача сопровождения

Оператор сервисного журнала умеет просматривать встроенные заявки, но хочет обмениваться CSV. Сначала докажите исправность окна, затем воспроизведите ошибки обмена. Исправляйте их по отдельности: так повторная проверка показывает причину улучшения. После общей диагностики добавьте выборку для оператора и выполните собственное предметное правило.

Что считать рабочей копией

Распакуйте исходный проект по ссылке под заголовком в папку Source. Для экспериментов создайте её копию Work. Не меняйте Source. CSV-заготовка нужна для сравнения и воспроизведения; исправленный пример открывайте для сверки после собственного исправления. Это три версии одного приложения с одинаковыми именами классов, поэтому их исходники нельзя складывать в один проект.

Среда

В проверенной среде используются Windows, Visual Studio и .NET SDK 10.0.401. В файле ServiceDesk.csproj указан net10.0-windows и UseWPF=true. SDK компилирует проект; Desktop Runtime выполняет WPF-приложение. Если Visual Studio не поддерживает этот SDK или не видит WPF-компоненты, остановите сборку и сообщите преподавателю фактическую ошибку. Не меняйте целевую платформу наугад.

internal record ReadResult(List<Ticket> Tickets, List<string> Warnings);

Код для указанного изменения

    private const string Header = "Id;Item;Owner;Due;Status";

    public static ReadResult Read(string path)
    {
        var tickets = new List<Ticket>();
        var warnings = new List<string>();
        var lines = File.ReadAllLines(path, Encoding.UTF8);
        if (lines.Length == 0 || lines[0].TrimStart('\uFEFF') != Header)
            throw new InvalidDataException($"Ожидается заголовок {Header}");
        for (int index = 1; index < lines.Length; index++)
        {
            if (string.IsNullOrWhiteSpace(lines[index])) continue;
            var cells = lines[index].Split(';');
            string? reason = null;
            if (cells.Length != 5) reason = "ожидается пять полей";
            else if (!int.TryParse(cells[0], out _)) reason = "неверный Id";
            else if (string.IsNullOrWhiteSpace(cells[1]) || string.IsNullOrWhiteSpace(cells[2])) reason = "пустое обязательное поле";
            else if (!DateTime.TryParseExact(cells[3], "dd.MM.yyyy", CultureInfo.InvariantCulture, DateTimeStyles.None, out _)) reason = "неверная дата";
            else if (cells[4] != "Открыта" && cells[4] != "Завершена") reason = "неверный статус";
            if (reason != null) { warnings.Add($"Строка {index + 1}: {reason}"); continue; }
            tickets.Add(new Ticket(int.Parse(cells[0], CultureInfo.InvariantCulture), cells[1], cells[2],
                DateTime.ParseExact(cells[3], "dd.MM.yyyy", CultureInfo.InvariantCulture), cells[4]));
        }
        return new ReadResult(tickets, warnings);
    }

Смысл чтения

ReadAllLines получает строки в UTF-8. Заголовок проверяется до цикла. Пустые строки не являются заявками; пять полей проверяются до индексов. TryParse возвращает успех вместо исключения; TryParseExact требует однозначную дату. reason содержит первую найденную причину. continue пропускает только текущую строку. index+1 — её физический номер с учётом заголовка. Хорошая строка создаёт Ticket и остаётся доступной.

Константа Header уже появилась вместе с Read: если её ещё нет, добавьте private const string Header = "Id;Item;Owner;Due;Status"; непосредственно после открывающей скобки CsvStore. Код для указанного изменения

    public static void Write(string path, IEnumerable<Ticket> tickets)
    {
        var lines = new List<string> { Header };
        foreach (var t in tickets)
        {
            if (new[] { t.Item, t.Owner, t.Status }.Any(value => value.Contains(';') || value.Contains('\n') || value.Contains('\r')))
                throw new InvalidDataException("В поле нельзя использовать разделитель или перевод строки");
            lines.Add($"{t.Id};{t.Item};{t.Owner};{t.Due.ToString("dd.MM.yyyy", CultureInfo.InvariantCulture)};{t.Status}");
        }
        File.WriteAllLines(path, lines, Encoding.UTF8);
    }

Зачем две проверки

Сначала формируется весь список строк, затем File.WriteAllLines записывает его в UTF-8. ToString с InvariantCulture сохраняет dd.MM.yyyy независимо от системной культуры. В этом простом контракте нет CSV-кавычек и экранирования: точка с запятой и перевод строки внутри поля отклоняются, чтобы не создать повреждённый файл. Отказ происходит до записи содержимого.

Заменить одно правило

Внутри CsvStore замените целиком метод CountOverdue следующим фрагментом. Не меняйте TestData.CountOverdue: он был правильным и нужен для сравнения. Два правила должны давать одинаковый результат на одинаковых данных.

Код для указанного изменения

    public static int CountOverdue(IEnumerable<Ticket> tickets, DateTime today) =>
        tickets.Count(t => t.Status != "Завершена" && t.Due.Date < today.Date);

Разобрать выражение

Count считает только элементы с истинным условием. Статус завершения исключается до сравнения дат. Due.Date и today.Date сравнивают календарные дни без времени. Срок сегодня ещё не просрочен. Параметр today позволяет проверить правило на заданную дату без изменения часов Windows.

internal static class OperatorView
{
    public static List<Ticket> Select(IEnumerable<Ticket> rows, DateTime today) =>
        rows.Where(t => t.Status == "Открыта" && t.Due.Date < today.Date)
            .OrderBy(t => t.Due).ThenBy(t => t.Id).ToList();
}

На копиях входа проверьте: верный файл; неполную строку после хорошей; неверные Id, дату и статус; пустые Item/Owner; файл только с заголовком; неверный заголовок; отсутствующий файл; строку с лишним разделителем. Для каждого случая укажите вход, действие, ожидаемые записи/сообщение, фактический результат и вывод. Header-only даёт пустой список без предупреждений; неверный заголовок запрещает загрузку; ошибочная отдельная запись не уничтожает хорошие.

Сохранение после отказа

Загрузите верный CSV, затем попробуйте файл с неверным заголовком. Благодаря назначению tickets только после успешного Read прежние данные остаются в памяти. Экспортируйте их и сравните все поля. Если запись файла запрещена или файл занят, окно сообщает ошибку экспорта; не считайте сообщение «Файл сохранён» доказательством без проверки файла.

Проверка исходной функции

После всех исправлений нажмите «Тестовые данные», «Просрочено», «Для оператора», «Все записи». Ожидаются две встроенные заявки, одна просрочка и восстановление двух строк. После повторного CSV-импорта выборка должна строиться по новому набору. Выполните полный цикл импорта и экспорта ещё раз: проверка отсекает случайные изменения за пределами D1–D3.

namespace ServiceDeskWpf;

internal record Ticket(int Id, string Item, string Owner, DateTime Due, string Status);

internal static class TestData
{

    [
        new Ticket(101, "Проектор", "Ирина", today.AddDays(-2), "Открыта"),

namespace ServiceDeskWpf;

public partial class App : Application
{
    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        if (e.Args.Length == 1 && e.Args[0] == "--test-built-in")
        {
            var rows = TestData.Create(DateTime.Today);
            Console.WriteLine($"test-records={rows.Count}; overdue={CsvStore.CountOverdue(rows, DateTime.Today)}");
            Shutdown();
            return;
        }
        if (e.Args.Length == 2 && e.Args[0] == "--self-test")
        {
            var result = CsvStore.Read(e.Args[1]);
            var target = Path.GetTempFileName();
            try
            {
                CsvStore.Write(target, result.Tickets);
                var again = CsvStore.Read(target);
                if (again.Warnings.Count != 0 || !result.Tickets.SequenceEqual(again.Tickets))

                Console.WriteLine($"tickets={result.Tickets.Count}; warnings={result.Warnings.Count}; overdue={CsvStore.CountOverdue(result.Tickets, DateTime.Today)}");
                foreach (var warning in result.Warnings) Console.WriteLine(warning);
            }
            finally { File.Delete(target); }
            Shutdown();
            return;
        }
        new MainWindow(e.Args.Length == 2 && e.Args[0] == "--demo" ? e.Args[1] : null).Show();

Для исправлений используйте точные замены выше. MainWindow.xaml и его код образуют связанную пару; App запускает именно этот класс окна.

MainWindow.xaml.cs

using System.Globalization;
using System.IO;
using System.Text;
using System.Windows;
using Microsoft.Win32;

namespace ServiceDeskWpf;

internal record Ticket(int Id, string Item, string Owner, DateTime Due, string Status);
internal record ReadResult(List<Ticket> Tickets, List<string> Warnings);

internal static class TestData
{
    public static List<Ticket> Create(DateTime today) =>
    [
        new Ticket(101, "Проектор", "Ирина", today.AddDays(-2), "Открыта"),
        new Ticket(102, "Ноутбук", "Павел", today.AddDays(-1), "Завершена")
    ];

    public static int CountOverdue(IEnumerable<Ticket> tickets, DateTime today) =>
        tickets.Count(t => t.Status != "Завершена" && t.Due.Date < today.Date);
}

internal static class CsvStore
{
    private const string Header = "Id;Item;Owner;Due;Status";

    public static ReadResult Read(string path)
    {
        var tickets = new List<Ticket>();
        var warnings = new List<string>();
        var lines = File.ReadAllLines(path, Encoding.UTF8);
        if (lines.Length == 0 || lines[0].TrimStart('\uFEFF') != Header)
            throw new InvalidDataException($"Ожидается заголовок {Header}");
        for (int index = 1; index < lines.Length; index++)
        {
            if (string.IsNullOrWhiteSpace(lines[index])) continue;
            var cells = lines[index].Split(';');
            string? reason = null;
            if (cells.Length != 5) reason = "ожидается пять полей";
            else if (!int.TryParse(cells[0], out _)) reason = "неверный Id";
            else if (string.IsNullOrWhiteSpace(cells[1]) || string.IsNullOrWhiteSpace(cells[2])) reason = "пустое обязательное поле";
            else if (!DateTime.TryParseExact(cells[3], "dd.MM.yyyy", CultureInfo.InvariantCulture, DateTimeStyles.None, out _)) reason = "неверная дата";
            else if (cells[4] != "Открыта" && cells[4] != "Завершена") reason = "неверный статус";
            if (reason != null) { warnings.Add($"Строка {index + 1}: {reason}"); continue; }
            tickets.Add(new Ticket(int.Parse(cells[0], CultureInfo.InvariantCulture), cells[1], cells[2],
                DateTime.ParseExact(cells[3], "dd.MM.yyyy", CultureInfo.InvariantCulture), cells[4]));
        }
        return new ReadResult(tickets, warnings);
    }

    public static void Write(string path, IEnumerable<Ticket> tickets)
    {
        var lines = new List<string> { Header };
        foreach (var t in tickets)
        {
            if (new[] { t.Item, t.Owner, t.Status }.Any(value => value.Contains(';') || value.Contains('\n') || value.Contains('\r')))
                throw new InvalidDataException("В поле нельзя использовать разделитель или перевод строки");
            lines.Add($"{t.Id};{t.Item};{t.Owner};{t.Due.ToString("dd.MM.yyyy", CultureInfo.InvariantCulture)};{t.Status}");
        }
        File.WriteAllLines(path, lines, Encoding.UTF8);
    }

    public static int CountOverdue(IEnumerable<Ticket> tickets, DateTime today) =>
        tickets.Count(t => t.Status != "Завершена" && t.Due.Date < today.Date);
}

internal static class OperatorView
{
    public static List<Ticket> Select(IEnumerable<Ticket> rows, DateTime today) =>
        rows.Where(t => t.Status == "Открыта" && t.Due.Date < today.Date)
            .OrderBy(t => t.Due).ThenBy(t => t.Id).ToList();
}

public partial class MainWindow : Window
{
    private List<Ticket> tickets = new();

    public MainWindow(string? demoPath = null)
    {
        InitializeComponent();
        if (demoPath != null) Loaded += (_, _) =>
            Dispatcher.BeginInvoke(System.Windows.Threading.DispatcherPriority.ApplicationIdle,
                new Action(() => LoadCsv(demoPath)));
    }

    private void LoadTestData_Click(object sender, RoutedEventArgs e) => LoadTestData();

    private void LoadTestData()
    {
        tickets = TestData.Create(DateTime.Today);
        TicketsGrid.ItemsSource = tickets.ToList();
        StatusText.Text = $"Тестовых записей: {tickets.Count}";
    }

    private void OpenCsv_Click(object sender, RoutedEventArgs e)
    {
        var dialog = new OpenFileDialog { Filter = "CSV (*.csv)|*.csv" };
        if (dialog.ShowDialog() == true) LoadCsv(dialog.FileName);
    }

    private void LoadCsv(string path)
    {
        try
        {
            var result = CsvStore.Read(path);
            tickets = result.Tickets;
            TicketsGrid.ItemsSource = tickets.ToList();
            StatusText.Text = $"Загружено: {tickets.Count}; пропущено: {result.Warnings.Count}";
            if (result.Warnings.Count > 0)
                MessageBox.Show(string.Join(Environment.NewLine, result.Warnings), "Предупреждения импорта");
        }
        catch (Exception ex) { MessageBox.Show(ex.Message, "Ошибка импорта"); }
    }

    private void SaveCsv_Click(object sender, RoutedEventArgs e)
    {
        var dialog = new SaveFileDialog { Filter = "CSV (*.csv)|*.csv", FileName = "export.csv" };
        if (dialog.ShowDialog() != true) return;
        try { CsvStore.Write(dialog.FileName, tickets); StatusText.Text = "Файл сохранён"; }
        catch (Exception ex) { MessageBox.Show(ex.Message, "Ошибка экспорта"); }
    }

    private void SelectForOperator_Click(object sender, RoutedEventArgs e)
    {
        var selected = OperatorView.Select(tickets, DateTime.Today);
        TicketsGrid.ItemsSource = selected;
        StatusText.Text = $"Для оператора: {selected.Count}; всего: {tickets.Count}";
    }

    private void ShowAll_Click(object sender, RoutedEventArgs e)
    {
        TicketsGrid.ItemsSource = tickets.ToList();
        StatusText.Text = $"Все записи: {tickets.Count}";
    }

    private void CountOverdue_Click(object sender, RoutedEventArgs e) =>
        StatusText.Text = $"Просрочено: {CsvStore.CountOverdue(tickets, DateTime.Today)}";
}

Что сверять

Сверьте имена классов и элементов, Click, формат даты и обработчики. В исправленном окне сохранена загрузка встроенных данных, добавлен CSV и отдельный просмотр для оператора. Если свой вариант отличается предметным правилом, оно должно находиться в OperatorView.Select и проверяться на своих контрольных данных.
