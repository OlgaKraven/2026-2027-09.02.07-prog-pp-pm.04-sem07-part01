# ПП.04.01 — сопровождение программного обеспечения

Производственная практика для специальности 09.02.07, квалификация «Программист». Сначала обучающийся собирает и проверяет приложение C# WPF на встроенных данных, затем подключает CSV и исправляет дефекты импорта, экспорта и расчёта. Версия 1.2 содержит точные последовательные изменения кода, 30 предметных правил с контрольными данными и процедуру обновления с резервной копией и откатом.
